# QA Python - Sprint 4 Project

## Описание
Это проект по автоматизации тестирования на Python с использованием pytest.  
В проекте реализованы автотесты для проверки функционала, с применением параметризации для удобства и масштабируемости тестов.

# Коментарии
Текущая функциональность, покрытая этими тестами, работает правильно.
